# Síncopa — Finanzas Modo Brutal

App de presupuesto personal con estética brutalist/cult.

## Deploy en Vercel (sin código)

1. Sube esta carpeta a GitHub
2. Ve a vercel.com → Import Project → selecciona el repo
3. Vercel detecta Next.js automáticamente → Deploy

## Desarrollo local

```bash
npm install
npm run dev
```
